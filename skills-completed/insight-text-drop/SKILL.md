# InsightTextDrop

Key insight text that drops from above with refined serif typography. A subtle gold gradient light sweeps across the text surface after landing, giving a premium editorial feel.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | — | Main insight text |
| `subtext` | `string` | `""` | Secondary line |
| `durationInFrames` | `number` | `90` | Total frames |
| `textColor` | `string` | `"#e2e8f0"` | Text color |
| `sweepColor` | `string` | `"#fbbf24"` | Gradient sweep color |
| `fontSize` | `number \| string` | `"5vw"` | Text size |
